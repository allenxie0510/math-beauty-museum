# 入口三维流体装置

## 后续更新：可见流动与参数对比（2026-10-08）

用户反馈初版看起来像静态造型。本次将原有微小点替换为 96 个（低功耗 60 个）明亮实例化粒子和渐隐尾迹，并减弱固定管线，让径向内流、旋转和轴向拉伸更容易辨认。尾迹在入口处截断，避免重新注入时跨越显示域画出错误连线。参数重建及场景卸载时释放实例化网格的专用缓冲。

环量 Γ 现在可在 −24 到 24 之间调整，主面板直接显示滑杆，负值反向旋转，零值保留汇聚和拉伸、消除旋转。增加细涡核（ν=.06, a=1.2）、宽涡核（ν=.4, a=.3）、反向旋转快捷比较。显示特征半径 δ=√(4ν/a)，它是涡量降至轴上值 1/e 处的尺度，不是可见流线束的外边界。

黏性、拉伸率、播放速度（0.25–2×）、暂停/继续、重置单独放在“调节涡核与流速”；公式及研究来源另行折叠。参数改变会暂停三件展品的轮播。流动时间单独累积，暂停/继续或切换播放速度不会跳到另一时间。系统减少动态效果偏好下仍保持静止并显示提示。

参数切换是不同稳态解析解之间的比较，不宣称求解时变参数下的非稳态 Navier–Stokes 方程。颜色编码角速度绝对值，按每组参数重新归一化；不能跨不同 Γ 直接比较颜色判断绝对速度。初版下文“固定 Γ=20”等描述仅为历史状态。

验收：45 项测试通过；包含环量反转、零环量、涡核尺度关系，以及实际三维粒子矩阵随时间改变、尾迹有限且不跨入口连接的检查。Vercel 构建及定向 ESLint 通过。Ego 桌面和手机验收了参数快捷比较、零环量、暂停恢复、速度调整及布局；暂停读数保持 33.195，2× 播放实测 0.8285 秒内推进 1.651 单位流动时间。截图见 `qa-fluid-motion/`。手机 390×844 无横向溢出。

## 初版记录

实施日期：2026-10-08。入口顺序为三维流体、复平方根曲面、四维超立方体；每件停留 12 秒。支持手动切换、暂停轮播、黏性和拉伸率调节。打开参数面板自动停留，次要说明折叠展示。减少动态效果偏好下默认不轮播，示踪点静止。

- [OpenAI 官方研究说明](https://openai.com/index/navier-stokes-solution/)署期为 2026-09-08；用户截图中的社交帖日期不能作为该研究的发布日期证据。
- [NavierStokesAndEuler 公开仓库](https://github.com/openai/NavierStokesAndEuler/tree/f9e8bc5b38b6e212696e8a30e3e91517af887bbd)，读取基准 `f9e8bc5b38b6e212696e8a30e3e91517af887bbd`，提交日期 2026-09-10。仓库包含 Lean 形式化及 Comparator 文件，不是可直接放入浏览器的三维动画组件。研究对于正黏性 Navier–Stokes 的主张涉及光滑外力；不能略去外力条件。本馆没有运行 Lean 或独立复核证明。
- 装置使用经典稳态 **Burgers 涡旋**。公式依据 Nolan 与 Farrell (1999), *Generalized Stability Analyses of Asymmetric Disturbances in One- and Two-Celled Vortices Maintained by Radial Inflow*, [正文式 3.1–3.3](https://brian-f-farrell.fas.harvard.edu/sites/g/files/omnuum10491/files/brian_f_farrell/files/generalized.pdf)。
- 经典方程、经典解析解与 OpenAI 研究分别标注。此模型展示径向内流、周向旋转、轴向拉伸与黏性平衡，不复现研究的奇点构造。全空间背景应变的总动能无限，不是有限能量千禧年问题的验证。

## 数学与实现

密度归一化，正黏性 ν，拉伸率 a，环量 Γ，外力 f=0：

```
∂t u + (u·∇)u = −∇p + νΔu,  ∇·u = 0
u_r = −a r / 2
u_z = a z
u_θ = Γ(1 − exp(−a r²/(4ν))) / (2πr)
ω_z = Γa exp(−a r²/(4ν)) / (4πν)
```

这里 ω_z 表示涡量；色彩编码的角速度为 Ω=u_θ/r，轴上极限 Γa/(8πν)。二者不能混用，角速度也不是线速度。青色到蓝色到橙色编码相对角速度，场景灯光会影响最终颜色。

`app/entrance/burgers-vortex.ts` 独立计算速度、涡量、压力梯度和示踪轨迹。使用 `expm1` 避免消减误差并补上轴处可去奇点。径向和轴向轨迹解析求解，角度采用 Simpson 积分。

`VortexSculpture.ts` 将轨迹生成真实三维管线，统一合并为一个 mesh，加一组运动示踪点。正常档 48 条流线、每条 224 段；低功耗档 30 条、112 段。数学 z 轴刚性旋转到场景竖轴，整体等比缩放。显示域截取至 |z|=2.65；示踪点走完显示域后重新注入，这是展示循环，不表示物理闭合轨道。模型形状稳态，光点表示流动；参数改变时重建管线并释放旧 GPU 资源。

黏性范围 0.06–0.40，拉伸率 0.30–1.20，固定 Γ=20。没有新增 AI 调用、服务器模拟任务或依赖包，计算在访问者浏览器完成。

## 验证

- `npm test`：43 项通过，包括新加的轴上平滑性、不可压缩性、解析涡量、轨迹导数和稳态动量平衡测试。
- 108 组参数/空间点的动量残差检查，中心差分步长 1e-4，实测最大分量残差约 3.25e-7。这是实现数值自检，不是新的数学证明。
- `npm run build:vercel` 与新增 TS/TSX、主场景的 ESLint 通过。
- Ego 浏览器：桌面 1440×1000、手机模拟 390×844；参数两端、恢复默认、三个装置手选、完整 0→1→2→0 自动轮播通过；截图位于 `qa-fluid/`。
- 手机布局无横向溢出；公式说明有内部滚动。滑杆使用显式有色轨道，避免全局 range 样式导致仅见滑块。
- 桌面参数重建后 GPU 资源计数保持 59 geometries / 30 textures，手机低功耗档为 51 / 24；未做所有设备性能保证或并发负载测试。

默认小派继续静音。手机既有小派悬浮角色可能覆盖右下展厅箭头，可拖动角色移开；这不是流体渲染依赖。
