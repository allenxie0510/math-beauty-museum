# Mahler 一屏操作页

实施日期：2026-10-08。按用户要求，先将 Mahler 改为与空间切片、环面等周一致的操作页构图。

## 布局

- 浅青灰背景；顶部标题、前沿来源标识和 2D/3D 切换。
- 左侧两张同尺寸模型画布，原形为暖橙，极对偶为青绿；对应面积/体积读数紧贴模型底部。
- 右侧将乘积置顶，接着是经典下界、圆/球参考值、形状预设、p 和剪切参数。
- 底部固定返回、公式与研究说明、恢复默认。恢复默认包含恢复三维、p=1、s=0、初始视角。
- 经典定义、计算方法及完整研究资料进入原生 dialog；Esc 只关闭说明，继续保留实验状态，关闭后焦点回到触发按钮。退出实验后焦点回到工坊入口。
- 常驻保留低维已有定理与 OpenAI 全维手稿主张的区别，以及只展示 Lp 家族及其剪切的范围说明。

## 绘制与范围

`MahlerSolidPlot` 使用画布实际宽高分配 DPR 缓冲，以较短边计算单位尺度，在长边方向居中。两个面板大小相同，不各自按模型包围盒缩放；保留同尺度正交投影和同步旋转。二维 SVG 使用等比 viewBox。修改配色以适应浅色背景，计算模块 `mahler-polar.ts` 未改变。

仅改动 Mahler，不迁移高斯素数和 Voronoi；本次没有增加 AI 请求或依赖。

## 验收

- `npm test`：45 项通过，包含原有二维/三维极对偶、端点、剪切不变性测试。
- 两个组件定向 ESLint、Vercel 构建通过。
- Ego 浏览器，桌面 1366×768：操作页及右栏无纵向溢出；所有主控件与底栏一屏可见。
- 手机 390×844：并排模型，参数双栏排列，页面与主体无滚动、无横向溢出，底栏横向排列。
- 低高度横屏 844×390：压缩标题和底栏，模型画布保留约 247×141 CSS 像素，右侧参数独立滚动，底栏始终可访问。
- 键盘旋转一图后两幅画布像素均改变；两个画布 CSS 尺寸与像素缓冲大小相同。
- 球体 p=2、s=0.8 时两侧体积均为 4.18879，乘积为 17.54596；二维圆乘积显示 9.86957（采样近似，与 π² 的误差在原有测试容差内）。
- p=8、s=−0.8 的手机显示、两个维度切换、重置、研究弹窗焦点与 Esc、返回工坊都已检查。
