# 数学美学展：沉浸式连续展馆设计规范

状态：静态方案已完成，等待视觉方向确认后进入 WebGL 开发。

## 1. 设计目标

展馆应当呈现一段连续的“发现数学之美”的空间旅程，而不是四个相互替换的展厅页面。空间、灯光、材质、数学装置和交互界面共同承担叙事。

核心体验目标：

- 进入展馆的第一眼形成清晰品牌记忆：`数学美学展 / MATH BEAUTY MUSEUM`。
- 从入口能够预见后续展厅，参观者始终知道下一段旅程在哪里。
- 四馆拥有不同气氛，同时共享统一建筑语言。
- 数学图形在暗场弧形大屏上成为视觉主角。
- 参数控制位于屏幕下方，像真实科技馆控制台，不再使用明亮的侧栏弹窗。
- 自发光、半透明、磨砂、粒子和反射材质有明确功能，不作为无目的装饰。

## 2. 当前结构与重构边界

当前 `MuseumCanvas` 在展厅切换时为每个馆重新建立一个独立的 Three.js 场景，并以三面墙、地面、天花和三块展板组成单个盒状空间。左右按钮触发场景替换，馆与馆之间不存在真实的空间关系。

重构后：

- 四馆、入口中庭和连接廊道存在于同一个持久 Three.js 场景中。
- 切馆动作变为相机沿空间曲线移动，而不是卸载并重建场景。
- 当前展板数据、公式、滑杆参数、发现进度与声音驱动逻辑继续保留。
- 当前弹窗滚动锁定继续保留，但探索界面改为“沉浸展项模式”。
- 数学花园作为旅程的尾声，与宇宙馆出口形成连续转场。

## 3. 空间叙事

### 3.1 序厅：数学之门

序厅是全馆视觉焦点，也是四条数学线索的起点。

- 顶部悬挂双层发光文字环：内环“数学美学展”，外环“MATH BEAUTY MUSEUM”。
- 文字环缓慢差速旋转，亮度随中心装置的变化呼吸。
- 中心装置命名为“连续体 / THE CONTINUUM”。
- 地面嵌入一条细发光路径，从中心装置分流并连接四馆。
- 左右门洞可以看到相邻馆的色光、轮廓或粒子，建立空间预告。

### 3.2 中心装置：连续体

装置不是单一雕塑，而是四种数学状态之间缓慢变形的参数曲面：

1. 自然状态：黄金角与叶序粒子从中心生长。
2. 建筑状态：曲面收束成悬链拱和受力网格。
3. 声音状态：表面成为利萨如波纹与频谱薄膜。
4. 宇宙状态：结构展开成对数螺旋与轨道粒子。

装置由半透明磨砂主体、细金属边缘和稀疏轨道粒子组成。每 12–16 秒完成一次状态过渡；鼠标移动只产生轻微视差，不改变叙事节奏。

### 3.3 连续展馆动线

采用环形主路径与局部捷径结合的布局：

`序厅 → 自然数学馆 → 建筑数学馆 → 声音数学馆 → 宇宙数学馆 → 数学花园`

空间变化规则：

- 每个馆入口使用 2–3 层不同尺度的曲面门框，产生景深。
- 墙体并非完全封闭；磨砂玻璃、穿孔网格或局部开口允许看到下一馆的光色。
- 走廊宽度、天花高度和转弯半径不断变化，形成收紧、释放、再聚焦的节奏。
- 发光路径贯穿全程，在不同馆只改变局部色温，不改变线宽与运动方向。
- 馆间转场保留 10%–15% 的前一馆色光，再逐渐混入下一馆色光，避免突然换景。

### 3.4 旅程节奏

- 序：高挑、对称、明暗平衡，建立品牌与世界观。
- 承：自然馆更柔软、更有生长感，空间逐渐展开。
- 转：建筑馆与声音馆加强结构、节奏和动态光影。
- 合：宇宙馆形成最深暗场与最大尺度视觉，随后进入开阔明亮的数学花园。

## 4. 四馆视觉与材质系统

| 展厅 | 主色光 | 空间母题 | 核心材质 | 动态语言 |
| --- | --- | --- | --- | --- |
| 自然数学馆 | 苔绿、柔金 | 生长、分枝、叶序 | 琥珀磨砂玻璃、半透明树脂、细纤维网 | 生长粒子、黄金角轨迹、缓慢呼吸 |
| 建筑数学馆 | 琥珀、暖白 | 拱、网格、受力路径 | 暖灰微水泥、阳极氧化金属、镜面模块 | 动态方块墙、悬链线、力流发光 |
| 声音数学馆 | 洋红、青蓝 | 波、干涉、节拍 | 波纹玻璃、穿孔金属、薄膜材质 | 频谱波、声压光带、麦克风响应 |
| 宇宙数学馆 | 深靛、冷白 | 轨道、螺旋、尺度 | 黑玻璃、烟灰亚克力、星尘体积层 | 轨道粒子、银河旋臂、视差星场 |

统一基底：

- 建筑墙面：暖灰微水泥，粗糙度约 0.72–0.86。
- 天花：石墨黑吸光材质，隐藏技术结构。
- 地面：深灰哑光树脂，局部保留低强度反射。
- 金属：深色拉丝铝，避免高亮镜面造成廉价感。
- 信息介质：磨砂玻璃与半透明网格，不使用厚重黑色边框。

## 5. 展项与沉浸互动模式

### 5.1 展厅浏览状态

- 墙面保留竖式主题展板，但展板成为进入主题的“入口界面”。
- 展板厚度、投影和墙面洗光继续存在；减少说明文字，只保留概念标题、核心公式和视觉预告。
- 点击展板后，相机向对应沉浸空间平滑推进，空间本身变暗并让大屏成为主视觉。

### 5.2 沉浸展项状态

画面分为三层：

1. 上层 65%–72%：深色弧形主屏，显示实时数学图形。
2. 下层 22%–28%：控制台，排列滑杆、旋钮、播放、声音输入与复位操作。
3. 边缘 6%：主题名称、核心公式、退出按钮和发现状态。

主屏规则：

- 背景使用深蓝黑或暖黑，而不是浅灰画布。
- 图形使用发光渐变、粒子、细轨迹和有限的体积光。
- 网格、公式和辅助线只在有助于理解时出现，透明度低于主图形。
- 弧形屏幕通过 Three.js 曲面几何或 CSS 透视实现，边缘不出现厚重装饰框。

控制台规则：

- 所有参数位于底部，并与图形建立颜色映射。
- 滑杆变化不仅更新数值，也沿控制台到主屏产生短暂光路反馈。
- 桌面端使用横向控制台；移动端折叠为底部抽屉，保留主图形可见面积。
- 声音馆继续支持三种音乐片段和麦克风输入，输入强度在控制台显示。

### 5.3 返回路径

- 退出沉浸模式后，相机沿原路径后退，回到打开展板前的角度与位置。
- 发现状态在展板边缘出现一次短促光脉冲，不弹出大型奖励卡。
- 背景页面、数学花园和其他展馆在沉浸模式中不可滚动或操作。

## 6. 灯光设计

灯光分为四个层级：

1. 建筑基础光：低亮度环境光，保证结构可读。
2. 墙面洗光：突出曲面、门洞和磨砂纹理。
3. 展项自发光：由屏幕、装置和粒子提供主题色。
4. 导览光：地面发光路径和入口边缘灯，仅承担动线指引。

控制原则：

- 同一画面最多存在一个主发光焦点和两个次级焦点。
- 自发光材质参与 Bloom，但限制阈值与半径，避免整场泛白。
- 半透明表面使用深色背景衬托，避免颜色发灰。
- 远处入口亮度略高于通道，持续暗示下一段路线。

## 7. WebGL 场景架构

建议把当前单馆组件拆分为：

- `MuseumWorld`：持久场景、渲染器、相机、灯光与性能档位。
- `MuseumAtrium`：文字环、中心装置和入口标识。
- `MuseumPromenade`：连续墙体、曲面门洞、地面路径与空间遮挡。
- `HallZone`：四馆的材质、展板、局部灯光和环境效果。
- `ImmersiveExhibit`：弧形屏幕、实时数学图形和底部控制台。
- `MuseumNavigation`：相机路径、当前区域、返回点和键盘/触控输入。
- `MuseumEffects`：粒子、Bloom、雾和低端设备降级。

实现原则：

- 仅创建一个 `WebGLRenderer`、一个主场景和一台主相机。
- 使用 `THREE.CatmullRomCurve3` 定义主参观路径，并为每馆设置相机停靠点。
- 通过相机位置插值、视线目标插值和缓动完成馆间移动。
- 展厅几何按区域分组，基于相机距离切换细节与粒子数量。
- 曲面墙、门框和控制台使用可复用几何与实例化网格。
- 发光文字使用 SDF/MSDF 字体或预生成 CanvasTexture，保证中英文清晰。
- 中心装置优先采用参数几何插值；粒子只承担边缘轨迹，不用粒子堆砌完整实体。
- 数学图形继续使用 Canvas/WebGL 程序生成，不依赖大体积视频资产。

## 8. 性能档位

### 高画质

- 像素比最高 1.75。
- 软阴影、Bloom、体积雾与完整粒子数量。
- 中心装置高细分曲面和实时材质变化。

### 标准画质

- 像素比最高 1.35。
- 保留 Bloom，减少阴影贴图和粒子约 40%。
- 半透明材质减少叠层。

### 节能画质

- 像素比最高 1.0。
- 关闭体积雾和动态阴影，使用烘焙光照感材质。
- 中心装置降低细分并减少粒子约 70%。
- `prefers-reduced-motion` 下停止自动旋转与持续相机漂移。

## 9. 开发阶段

### 阶段 A：连续空间骨架

- 建立单一持久场景。
- 完成序厅、环形路线、四馆入口和相机路径。
- 暂时使用简化展板，验证动线与视距。

### 阶段 B：序厅视觉焦点

- 加入双层发光文字环。
- 完成“连续体”装置的四状态变形。
- 加入地面导览光与入口预告光。

### 阶段 C：四馆材质与光影

- 按馆实现磨砂、金属、半透明与粒子语言。
- 加入馆间颜色混合与远景入口。
- 迁移现有 12 个展项数据与发现系统。

### 阶段 D：沉浸互动大厅

- 用弧形暗场主屏替换当前浅色预览弹窗。
- 把所有滑杆、声音与麦克风操作移到底部控制台。
- 完成进入、返回和滚动隔离。

### 阶段 E：性能与无障碍

- 加入三档画质和自动检测。
- 验证桌面、触控、键盘与减少动态效果模式。
- 完成降级提示与资源释放检查。

## 10. 验收标准

- 首屏可同时识别中英文馆名、中心数学装置和至少两个后续入口。
- 四馆处于同一 WebGL 场景，切馆过程中不销毁并重建渲染器。
- 任一馆都可以看见前馆或后馆的入口、光色或空间轮廓。
- 馆间切换表现为连续相机运动，不出现页面淡出后更换盒子的观感。
- 中心装置至少具有四种数学状态，并能连续动态过渡。
- 场景中实际使用自发光、半透明、磨砂、金属和粒子五类表现。
- 12 个现有数学主题均可进入沉浸展项模式。
- 沉浸模式主图形使用暗色弧形大屏，全部参数控制位于底部。
- 声音馆音乐片段与麦克风实时驱动继续可用。
- 关闭沉浸模式回到进入前的展厅视角，不触发页面滚动。
- 标准画质下桌面浏览保持流畅；低端设备可自动降级且内容完整。

## 11. 确认项

进入开发前只需要确认三点：

1. 是否采用静态效果图中的“深灰建筑基底 + 暖白导览线 + 四馆局部色光”。
2. 是否采用“双层发光文字环 + 连续体动态装置”作为序厅唯一主焦点。
3. 是否将所有展项统一改为“暗场弧形大屏 + 底部实体感控制台”的沉浸模式。
